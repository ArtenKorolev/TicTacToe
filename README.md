# Игра "Крестики-Нолики" на C++ с использованием SFML

Добро пожаловать в простую и увлекательную игру "Крестики-Нолики", реализованную с помощью C++ и библиотеки **SFML**. Проект демонстрирует использование 2D-графики и взаимодействия с пользователем.

## Игра через консоль

Этот репозиторий имеет ветку **cli**, в которой реализована логика 
игры через консоль, путем ввода координат клетки для хода. Игровое поле
отрисовывается также с помощью специальных символов в консоли. Однако, 
эта ветка больше не поддерживается и может содержать недоработки и устаревший код.

## Особенности игры
- **2D-графика** с использованием библиотеки **SFML**.
- Поддержка игры с компьтером.
- Реализация игровой логики: отслеживание побед, ничьих и хода игрока.
- Удобный графический интерфейс.

## Системные требования

Для запуска игры требуется:
- **Операционная система**: Windows, MacOS или Linux.
- **Компилятор с поддержкой C++11/17/20** (например, GCC, Clang, MSVC).
- **CMake** (опционально, если используете для сборки).

## Установка и запуск

### 1. Клонируйте репозиторий
Клонируйте проект на ваш локальный компьютер, не забудьте указать ветку **sfml**:

``` 
git clone -b sfml https://github.com/ArtenKorolev/TicTacToe.git
cd TicTacToe
```
### 2. Сборка проекта
Используйте CMake в связке с любым компилятором, библиотека SFML автоматически
установится с помощью FetchContent из CMake:

```
mkdir build && cd build
cmake ..
make
```

### 3. Запустите игру
После успешной сборки выполните:

```
./tic_tac_toe
```

## Управление

- Игрок играет за крестики и делает ход первым.
- **ЛКМ (левая кнопка мыши):** Сделать ход в выбранную клетку.
- Победитель определяется автоматически.
